# Hopelink_foundation_Haja_Jenabu_Bah_905006101# HopeLink Foundation

HopeLink Foundation is a multi-page non-profit organization website dedicated to uplifting vulnerable children, families, and communities in Sierra Leone through education, healthcare, food security, community development, and environmental protection.

## 🌟 Features

- **Responsive Multi-Page Layout**: Fully functional pages including Home, About Us, Our Programs, Get Help, Get Involved, and Contact.
- **Dynamic Hero Sections**: Clean typography with call-to-action buttons for donations and learning more.
- **Impact Statistics**: Showcasing key metrics such as children supported, community projects, volunteers, and years of impact.
- **Key Programs Grid**: Visual cards highlighting core foundation pillars.
- **Testimonial Section**: Real stories and beneficiary feedback.
- **Comprehensive Footer**: Quick navigation links, contact details, and organization branding.

## 🛠️ Technologies Used

- **HTML5**: Semantic document structuring.
- **CSS3**: Custom grid layouts, flexbox, and responsive design styling.
- **Git & GitHub**: Version control and project deployment.
